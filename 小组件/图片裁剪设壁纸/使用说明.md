# 图片裁剪设壁纸

双击 `启动图片裁剪设壁纸.sh`，选择“运行”即可启动。

使用方法：

1. 点击“选择图片”。
2. 裁剪比例默认与当前屏幕一致，也可以选择其他固定比例。
3. 在选框内部拖动可移动范围，拖动四个白色角可等比例缩放。
4. 点击“裁剪并设为壁纸”。

需要换回 Ubuntu/GNOME 的系统默认壁纸时，点击“恢复系统默认壁纸”并确认。该操作不会删除任何图片。

原图不会被修改。裁剪后的图片保存在图片目录下的 `裁剪壁纸` 文件夹中。

如果双击没有出现“运行”选项，可在此文件夹打开终端并执行：

```bash
./启动图片裁剪设壁纸.sh
```

本程序适用于 Ubuntu GNOME 桌面，需要 Python 3、GTK 3 和 Pillow；当前系统已经具备这些组件。
